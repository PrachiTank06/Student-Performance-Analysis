# 📊 Student Performance Analysis

## 📌 Project Overview

This project analyzes student performance using Python. The dataset is explored to understand the factors that affect students' academic performance.

The project includes data visualization and exploratory data analysis (EDA) using different charts.

---

## 🎯 Objectives

- Analyze student performance
- Explore relationships between different factors
- Visualize data using charts
- Understand academic trends

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code

---

## 📂 Dataset

Student Performance Dataset

Files Used:
- student-mat.csv
- student-por.csv

---

## 📈 Visualizations

This project includes:

- Age Distribution
- Gender Distribution
- Final Grade Distribution
- Average Grades
- Correlation Heatmap
- Study Time vs Grade
- Internet Access vs Grade
- Mother Education vs Grade
- Father Education vs Grade
- Failures vs Grade

---

## 🚀 How to Run

1. Clone the repository

2. Install the required libraries

bash
pip install pandas matplotlib


3. Run

bash
python main.py
